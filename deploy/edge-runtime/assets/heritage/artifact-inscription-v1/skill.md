# 器物铭文识读 Skill

这不是新训练的 LoRA，而是对既有「碑拓视觉 LoRA」的受控复用。它只接受用户为铭文单独拍摄并尽量裁紧的细节照；6–8 张环绕图仍只服务 2.5D 重建，绝不自动裁成铭文证据。

端侧对同一张细节照依次运行 Qwen3-VL-2B Base 与 `rubbing-vision` LoRA。若一方出现复读、超长输出或偏离 OCR，则使用另一方；若两个可读候选明显冲突，展示双候选并等待用户确认。只有通过门控或经用户确认的原始转录，才交给共享 Qwen 语言主干断句与今译。

独立博物馆样本显示：碑拓 LoRA 在裁紧的九字铜镜铭文上胜过 Base，但对整器小字、环形长铭和另一件金文未稳定获胜。因此该 Skill 的产品定位是「近拍细节上的候选增强器」，不得宣称为普适器物 OCR。
