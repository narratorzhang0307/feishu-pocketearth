# 配音与字幕使用说明

## 录音策略

只重录 `03_Google版_新增替换口播.txt` 中的 5 组连续区间。每组单独录一条，首尾各留 0.3 秒环境静音，后期按 SRT 时间点贴回。

第二轮稿已按时长压到约 4.7-5.3 个有效字符/秒；英文模型名可以自然放慢，不要逐字赶拍。

## 统一读法与口径

- Gemini：保持英文产品名，不说“GMI 模型”；
- Gemma 3n E2B IT：建议读作“Gemma three n，E two B，instruction-tuned”；
- int4 Web：读作“int four Web”；`.litertlm` 只保留在画面字幕，口播可说“LiteRT-LM 模型包”；
- MediaPipe LLM Inference Web：首次完整读出，后续简称“MediaPipe 端侧运行时”；
- MediaPipe：读作“Media Pipe”；
- GMI：只说“可选备用传输”，并说明默认走 Google Gemini API；
- RunTrace：读作“Run Trace”；
- cultural bridge：可先说“文化桥”，英文只在第一次出现时补充。

## 画面角标建议

- Gemini 云端：`GOOGLE GEMINI API · official direct`；
- 备用传输（仅实际启用时）：`optional fallback · GMI transport`；
- Gemma 端侧：`GOOGLE AI EDGE · local · no cloud API`；
- 看展搭子：`ZH guide · EN guide · timeline · cultural bridge`；
- 写入地球：`suggest → user confirm → pin`；
- 本地演示：`LOCAL DEMO · no live API call`。

## 不要补录的技术名

不要为了显得“Google 技术多”而加入 Firebase、Vertex AI、Google ADK、Google Search Grounding、Gemini Nano。当前代码没有使用它们，加入只会削弱可信度。
