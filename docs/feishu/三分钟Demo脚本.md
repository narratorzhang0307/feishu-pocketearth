# 三分钟真机 Demo 脚本

## 0:00–0:20 先展示结果

- 在飞书消息卡片点击“查看知识地球”。
- 展示已经落位的地点、飞书文档中的页码/原文证据，以及多维表格记录。
- 一句话价值：把散落在 PDF 和图片里的地点，变成飞书里可审核、可协作、可继续自动化的知识资产。

## 0:20–1:35 跑核心流程

- 从飞书工作台打开 Pocket Earth，指出右上角“飞书已认证”。
- 上传一份带多个地点的真实 PDF。
- 连续展示状态：飞书任务队列 → PaddleOCR → Qwen 证据抽取 → 等待人工确认。
- 强调每一项都有页码和原文证据，Qwen 没把握的坐标为空。

## 1:35–2:20 人工确认与写回

- 排除一条误识别，修订一个现代地名，补一个经纬度。
- 点击“确认并写回飞书”。
- 打开新生成的飞书文档；快速展示多维表格和完成消息卡片。

## 2:20–2:50 证明不是套壳

- 展示任务审计信息：同一个 taskId、文件 SHA-256、工作流版本。
- 用一句话说明分工：飞书负责身份/触发/审核/协作/沉淀，OCR+Qwen 负责识别/抽取/判断，两边缺一不可。
- 可快速重复提交同一文件，展示幂等复用同一任务。

## 2:50–3:00 收尾

- 回到知识地球，给出使用场景：旅行研究、课程资料、展览档案、团队调研。
- 发布社媒时带活动要求的话题标签，并在投稿表单提交产品介绍、Demo 链接和本指南。
