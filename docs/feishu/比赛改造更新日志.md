- 新增 `/feishu` 原生工作台及 JSSDK 免登。
- 新增服务端短时会话，飞书用户 token 不下发浏览器。

### AI 参与核心运行

- 新增 PaddleOCR / PP-Structure 真实服务适配契约。
- 新增 Qwen 严格 JSON 地点抽取，逐项验证页码与原文证据。
- 新增“坐标不确定即为空”的人工审核环节，禁止模型猜测。
- OCR 未配置、Qwen 空结果、非 JSON 或证据不落在原页时明确失败，不使用假数据兜底。

### 可演示与可验收

- 新增实时四段进度、失败重试、逐条证据审核和经纬度修订。

- 新增回调安全、证据约束、幂等任务、失败闭锁和 taskId 一致性测试。

## 第二轮可靠性迭代

- 新增可 Docker 部署的 PaddleOCR 3.7 / PP-StructureV3 服务，不再只有 OCR 接口契约。
- 新增任务磁盘快照与重启恢复；快照明确排除原始文档 Base64 和飞书用户令牌。
- 新增分阶段写回检查点，文档、文档块、多维表格和消息卡片可独立恢复。
- 写回失败只返回人工审核阶段，不再重复 OCR 和 Qwen 付费推理。
- 完成页在配置 Mapbox Token 时使用真实交互地图，点击地点可查看页码、置信度和原文证据。
- 无地图 Token 时仍保留可用降级视图，避免现场网络或配置问题导致白屏。

## 第三轮上线闭环迭代

- 修复加密事件回调只有验签、没有解密的缺口；现已覆盖签名时间窗、AES-256-CBC 解密、
  解密后 Verification Token 校验和加密 URL challenge。
- 新增单实例 24 小时 eventId 重放窗口，飞书重试不会重复进入后续事件处理。
- 新增 `npm run feishu:preflight`，上线前检查真实凭据、公网 HTTPS、危险开关、OCR 鉴权、
  多维表格完整性与上传上限；结果不包含密钥值。
- 新增 `Dockerfile.feishu` 与 `compose.feishu.yaml`，主服务和 PaddleOCR 使用独立非 root
  容器、内部 OCR 网络、任务数据卷和模型缓存卷。
- Compose 构建时只注入可公开的 Mapbox Token；飞书、Qwen 与 OCR 密钥只在运行时提供。

## 第四轮比赛合规与飞书界面收口

- 原 Pocket Earth 地球仍为默认页；飞书入口直接嵌入地球，不维护第二套工作台作为比赛主入口。
- 将飞书文档直读改为首要的一键流程，不再要求用户先猜 Frost 路由话术：
  `飞书身份 / 原文 → Qwen 证据抽取 → 人工确认 → 地球 + 源文档 / 多维表格`。
- 飞书版 Photos 移除“安装端侧语义模型”子页，收口为：本地查重与技术检测 → Qwen 建议 → 用户确认 → 杂志 / 日历 / 飞书照片表。
- Skills Plaza 去掉 Qwen 基座、MNN、模型大小和真机实验展示，只保留用户能理解的能力、权限、Data Pack 与确认门禁。
- 照片写入服务端增加二次隐私清洗：`data:`、`blob:`、`file:`、Base64 与本机文件对象不得进入多维表格 JSON。
- 删除 Earth Answer 页底部“00:00 解锁 / 端侧留痕 / 软硬同版”功能块，并去掉主卡、往日卡和日期选中态投影。
- 新增比赛要求逐条验收表；三分钟 Demo 改为真实飞书文档主链，PDF / OCR 仅作可选增强。
