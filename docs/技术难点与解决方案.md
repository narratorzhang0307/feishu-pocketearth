# Pocket Earth · Google AI 技术难点与解决方案

本文对应当前 Google AI Edition 的真实实现。所有路径均可在仓库中核验，模型命中、规则命中、降级和用户确认分别记录，不把静态文案当作技术接入证据。

## 1. 两套端侧推理平面

Pocket Earth 同时包含浏览器端和实体硬件端，两者共享 Google-first 路由原则，但使用不同的运行环境。

### 1.1 浏览器端

- 模型：Google Gemma 3n E2B IT int4 Web。
- 调度：MediaPipe LLM Inference Web 与 WebGPU。
- 适用任务：隐私预检、意图预分类、候选排序、短文本生成和单图预处理。
- 权重交付：同源 Range 请求；用户主动加载；成功后依赖浏览器缓存。
- 失败路径：规则、目录、缓存和手填继续可用；失败本身不构成上传授权。

关键实现：

- `frost-agent/edge/gemmaEdge.ts`
- `frost-agent/edge/gemmaRuntime.ts`
- `src/components/GemmaLocalPanel.tsx`
- `server.mjs` 中的同源模型 Range 路由
- `scripts/verify-gemma-runtime.mjs`

### 1.2 Frost Edge 树莓派端

- 模型：Google Gemma 4 E4B IT QAT Q4_0 GGUF。
- 运行时：独立 `llama-server` 进程，仅监听 `127.0.0.1:8787`。
- 适用任务：硬件意图预分类、候选排序、短答和断网降级。
- 服务隔离：模型、运行时、缓存、服务和部署目录均使用 `pocket-earth` 命名空间。
- 权重管理：模型文件不进入 Git；安装脚本核对文件大小与 SHA-256，服务预检读取 `/v1/models`。

关键实现：

- `hardware/frost-edge-google/raspi/frost_pi_gemma.py`
- `hardware/frost-edge-google/raspi/pocket-earth-gemma.service`
- `hardware/frost-edge-google/raspi/install-gemma-edge.sh`
- `hardware/frost-edge-google/raspi/frost_pi_live_preflight.py`
- `hardware/frost-edge-google/sunset-radio/raspi/edge.py`

## 2. Google Gemini 云端能力与传输分离

复杂多语理解、展签结构化、历史时间线、跨文化解释和公共知识双角色审查由 Google Gemini 承担。服务端优先使用 Google 官方 Gemini API；在官方密钥不可用且明确配置 GMI 时，只允许 GMI 传输 Google Gemini 模型。

每次云端调用分别记录：

- `provider`：对外提供请求的服务端路径。
- `modelOwner`：固定为 Google。
- `transport`：官方 Gemini API 或 GMI 备用传输。
- `model`：实际 Google Gemini model id。
- `latencyMs`、`error`、`fallback`：运行结果和降级原因。

服务端白名单拒绝非 Google 生成模型。两条云路径均不可用时，系统返回规则、目录、缓存和手填，不转发到其他生成模型。

关键实现：

- `knowledge/google-provider.mjs`
- `server.mjs` 中的 `/api/frost-llm` 和云视觉确认路由
- `scripts/verify-google-knowledge.mjs`
- `gmi-verify.mjs`

## 3. Harness 路由与可观测性

Frost Agent Harness 将一次请求拆成 Shell、Memory、Router、Brain、Boundary、Validator、Critic、Skill、Confirm Gate 与 RunTrace。路由顺序固定为：

1. 确定性规则快路。
2. Gemma 端侧判断。
3. 隐私与上传边界。
4. Gemini 复杂理解。
5. Schema、Validator 与 Critic 校验。
6. 用户修改与确认。
7. 写入私人地球、公共知识草稿或硬件白名单动作。

规则命中会标记 `local-rule`，模型命中会记录实际模型。调用超时、设备不支持、权重未加载、云端拒绝和用户取消均拥有独立状态。RunTrace 因此可以回答“由谁处理、在哪里处理、花了多久、为什么降级”。

## 4. 建议后确认

模型输出首先成为草稿。真正写入空间知识对象前需要满足：

- 字段通过受控 Schema。
- 地点通过城市、展馆、别名和坐标目录校验。
- 文化表述通过 Critic 检查。
- 用户可以修改字段与个人感受。
- Confirm Gate 收到明确确认。

未经确认，Agent 不能修改私人地球、发布公共知识或执行硬件动作。位置缺少可靠证据时，系统要求用户选择或手填，不伪造坐标。

## 5. 看展闭环

看展搭子把公开展签或文字描述转换为受控空间对象：

1. 端侧识别公开展签与敏感信息。
2. 云视觉需要再次说明用途、内容和 provider，并等待用户确认。
3. Gemini 生成中英文名称、年代、材质、器类、展馆、中文导览、English guide、时间线和事实型 cultural bridge。
4. Validator、Critic、朝代表、展馆表和别名表校验结果。
5. 用户修改并确认。
6. 对象钉到实际观看展馆，保存来源、模型路径、个人注释和确认状态。

最终对象可以从 Private Map 按城市、展馆与时间再次打开。旅行、书影音、照片和 Jot 使用同一空间数据契约。

## 6. Private Earth 与 Public Earth 分轨

Private Earth 保存个人经历，主要存储在浏览器 localStorage 与 IndexedDB。Public Earth 保存经过来源审查、双角色核验、确定性评分和人工发布闸的公共知识。

公共知识流水线包含：

1. 八个领域 Scout 发现候选信号。
2. Claim Intake 把内容整理为可验证主张。
3. Evidence Scout 保存公开来源、日期和发布方。
4. Gemini Investigator 建立受证据约束的论证。
5. Gemini Skeptic 检查断章取义、来源洗白和证据缺口。
6. Deterministic Judge 计算 Truth Score 和 verdict。
7. Receipt Keeper 保存来源、哈希和版本路径。
8. 人工发布闸决定是否进入 Public Earth。

模型输出不能成为新的独立来源，也不能自动批准发布。公共知识支持 Daily Knowledge 和 Pocket Podcast；硬件只读取已经通过核验的公共内容。

关键实现：

- `knowledge/daily-worker.mjs`
- `knowledge/daily-service.mjs`
- `knowledge/google-provider.mjs`
- `scripts/verify-google-knowledge.mjs`
- `frost-agent/skills/public-knowledge/`

## 7. Frost Edge 三个真实入口

Frost Edge 在树莓派与 Whisplay 上提供：

- 日落电台：按照城市、时间、日落和环境信号选择本地内容。
- 口袋播客：读取已核验公共知识，生成文字简报和可播放节目。
- 地球答案：围绕地点与公共知识进行本地问答，复杂请求再升级 Gemini。

三个入口共用 Frost Agent 人格、Gemma 端侧服务、Gemini 云升级、按钮事件、屏幕状态和隐私边界。硬件事件限定为公共、低风险、可缓存白名单，不同步私人记忆原文、原图、完整画像、精确坐标或云密钥。

## 8. 隐私边界

### 8.1 图片

- 人脸、证件、手机号、卡号和精确定位先由端侧规则识别。
- 公开展签进入云视觉前需要二次确认。
- 取消后仍可使用文字、目录和手填。
- 云视觉失败不会自动转发到其他 provider。

### 8.2 语音与摄像头

- 麦克风临时文件处理后删除。
- 摄像头只在用户明确操作时采集单帧。
- 临时帧完成分析后删除。
- 不执行身份识别、面部情绪推断或后台持续拍摄。

### 8.3 动作

- 模型只能提出候选动作。
- 城市、曲目、坐标和设备命令必须通过本地目录与白名单。
- 后台检查保持静音，不自动播放内容。

## 9. 纵深降级

每个概率性组件都有可解释降级路径：

| 缺位或故障 | 可继续使用的能力 |
| --- | --- |
| WebGPU 不可用 | 规则、目录、缓存、手填、Private/Public Earth 浏览 |
| 浏览器 Gemma 未加载 | 规则快路和用户确认后的 Gemini |
| 树莓派 Gemma 服务不可用 | 确定性硬件命令、白名单内容和上一有效缓存 |
| Gemini 不可用 | 本地草稿、受控字段、目录与手填 |
| 地图定位失败 | 城市或展馆选择；无可靠坐标则不落点 |
| 3D/AR 失败 | 看展主闭环继续完成 |

降级不会降低隐私门槛，也不会把端侧失败等同于云端授权。

## 10. 独立部署与核验

Google 版使用独立域名、目录、端口、PM2 进程、知识 Worker 和树莓派 systemd 服务。部署脚本只操作 Pocket Earth Google 命名空间。

公开核验入口：

- 产品 Demo：`https://pocketearth-google.throughtheglass.art/`
- 健康检查：`https://pocketearth-google.throughtheglass.art/healthz`
- Frost Edge 数字孪生：`https://pocketearth-google.throughtheglass.art/hardware-digital-twin.html`

本地核验包括 TypeScript、生产构建、服务语法检查、知识 Worker、Gemma 运行时 smoke、树莓派预检、Whisplay 预览和硬件边界测试。真机记录包含模型 SHA-256、服务状态、请求输出、延迟和资源占用，便于读者从文档回到代码与运行事实。
