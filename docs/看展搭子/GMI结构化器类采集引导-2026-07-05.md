# GMI 结构化器类采集引导补强

本轮补强看展搭子链路中的一个小闭环：当 GMI 结构化补全只返回 `拓本`、`摄影`、`印刷品` 或 `宣传品` 这类器类，而没有同步补出材质、标题关键词或展签原文时，采集引导仍应落到平面多图方案。

## 演示价值

- 真实展签里常见“碑拓 / 拓本 / 摄影作品 / 印刷宣传品”只在类别字段出现，不能依赖标题或材质一定含有平面关键词。
- 平面类展品不适合绕拍 3D 视频，应该提示用户正对分块、多图覆盖、避免玻璃反光。
- 这让“GMI 结构化补全字段 → 自动草稿 → 类型化采集引导 → KIRI 输入质量更稳定”的叙事更普适。

## 本地验证

- 新增 `src/app/lib/exhibition/captureGuide.structured.test.ts`，使用 mock artifact 验证 `category: '拓本'`、`category: '摄影'`、`category: '印刷品'` 与 `category: '宣传品'` 都进入 `flat` 引导。
- 不调用真实 GMI 或 KIRI API。
