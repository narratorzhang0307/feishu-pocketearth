## 1. 重建管线三档（把"绕拍→出真 splat"补上）

### ① 手动导入 .ply/.splat（★★★★★ 现在能做，零外部依赖）—— 下一步优先
用户在 **Scaniverse**（完全端侧、离线、免费、约 1 分钟出 PLY，安卓/iOS 都有）或 KIRI/Polycam 扫真展品 → 导出文件 → Pocket Earth `<input accept=".ply,.splat,.glb,.ksplat">` 收 → 存 IndexedDB blob → 附展品钉地球。把"重建"外包给成熟手机 app，我们只做存/定位/钉/看。
- 新增 `src/app/lib/exhibition/splatStore.ts`：`keyedStore<{id,blob,format,bytes}>('pe-splats')`（命名 `pe-*` 自动被 demoReset 清）。
- userMark.meta 存 `{splatId, format, thumb}`（**splat blob 绝不进 localStorage/dataURL**，>20MB 会爆）；详情时从 IDB 读 blob → `URL.createObjectURL` 喂 ExhibitViewer。
- ExhibitionRunPage 草稿卡加「导入 3D 文件」按钮（旁边就是现有「绕拍生成 3D 示例」）。

### ② KIRI 云 API（★★★★☆ 端点已核实，唯一未知=开发者 token/credit）
录视频/多图 → 代理上传 KIRI → 轮询 → 下载 zip 解 .ply → 钉地球。契约（逐页核实）：

| 用途 | Method + URL | 关键点 |
|---|---|---|
| 3DGS 视频 | `POST api.kiriengine.app/api/v1/open/3dgs/video` | multipart videoFile(≤1920×1080,≤3min)、isMesh、isMask；返回 data.serialize |
| 多图 | `POST .../api/v1/open/3dgs/image` | imagesFiles[]（20–300 张）；返回 data.serialize |
| 轮询 | `GET .../api/v1/open/model/getStatus?serialize=` | **1=失败 2=成功 3=排队**（反直觉） |
| 下载 | `GET .../api/v1/open/model/getModelZip?serialize=` | data.modelUrl(zip 直链，**仅 60 分钟**，含原生 3DGS .ply) |
| 余额 | `GET .../api/v1/open/balance` | 403=余额不足 |

- 全程 `Authorization: Bearer <KEY>`。**须注册 KIRI Developer 拿 token；新号 10 免费 credit，1 scan≈$1，最低充值 $500，定价测试期会变。**
- server.mjs + vite.config.ts 两路加 `/api/kiri`（照 handleUnsplash），三动作 upload/status/zip；**SSRF 只放行 api.kiriengine.app**；op=zip 只回 modelUrl 让前端 60 分钟内直取。
- **大视频上传须流式转发**：server.mjs 的 readBody 一次性 Buffer.concat 无上限会 OOM，KIRI 上传单独走 raw stream。poll 优先，webhook 标 P2（本项目无状态层）。
- 输出是 .ply（不是 .spz；.spz 是 KIRI 独立 web 工具无 API）；ExhibitViewer 吃 .ply 没问题。

### ③ 端侧 Brush（★★☆☆☆ 只进路线图）
ArthurBrussee/brush（Rust+Burn+WebGPU）真实活跃，但 Web 版官方仅 Chrome 134+ on Win/macOS（不覆盖 iOS Safari，安卓要 NDK），且只吃 COLMAP/Nerfstudio 格式不自带 SfM →「安卓拍完一键端侧重建」当前不成立，别写进 UI 承诺。价值=端侧查看器候选 +「隐私不出端」叙事。**用户用安卓（Chrome WebGPU 可用），是这条路线的可行前提，但仍需 NDK 打包，非近期。**

## 3. GMI 在 3D 线能帮什么
- GMI **无裸 GPU**（只 serverless 推理），跑不了自建 COLMAP+gsplat → 真几何走 KIRI/端侧，不指望 GMI GPU。
- GMI **视频 i2v/r2v**（kling-3.0-turbo-i2v、happyhorse-1.1-i2v，走 console 异步队列）可作**「轻量 3D 替代/环绕预览」**：多张展品照 → 环绕短视频，覆盖那些无法真重建（玻璃柜/只能拍正面）的展品，与真高斯泼溅分层并存。
- Google Gemini 图像模型负责明信片草稿；公开展签的云视觉识别只使用 Google Gemini，并在上传前取得用户明确同意。
